# 对话 harness 调整 · 2026-10-09

原先普通追问统一输出论文陈述、一般知识、推测、缺口四节；关键词触发
固定补读前两篇，提到“我的项目”就容易进入方案流程。这些限制直接影响多样问法。

新的普通对话流程：模型选择 answer / search_web / read_webpage / search_papers / read_paper /
project_context → 宿主执行一个读取动作 → 模型观察结果再选择 → 生成回答。
最多 5 个动作，重复动作停止；工具失败作为上下文交给回答步骤。无需新增框架。

职责划分：

- `agent/dialogue.py` 管理小循环、预算和工具范围，复用现有注册表。
- `agent/explanation.py` 允许模型组织段落、表格、代码等内容，并继续校验论文引文。
- `agent/conversation.py` 管理用户/项目范围、证据持久化和消息审计。
- 显式 research / plan / feedback 接口沿用原契约；auto 时事研究走同一个对话循环，方案仍保留规则路由。

普通知识和改写无需论文。未绑定项目时可以先讨论初步做法；没有技术标签的“懂了”
作为普通对话处理，不写学习事件。提到项目本身不再强制生成方案。

论文事实仍需来源与原文子串；无效陈述不交付。自然回答只显示紧邻陈述的来源链接，
完整引用、原始模型草案和错误保存在 grounding 元数据。字面匹配不证明语义支持。
推测和实际影响回答的缺口保留简短标识，普通知识不自动成为学习证据。

读取只能使用允许的动作；论文 URL 来自已有证据或本轮检索结果；项目检索绑定当前
会话的项目，并复用精确文件外发授权。禁止检索的明确指令由宿主再次检查。
没有模型可调用的写入、执行实验或 shell 动作。初次会话的工具轨迹写入消息元数据；
已有研究任务同时写入其 Trace。补读失败、未命中或正文降级不会覆盖原正文。

## 验证入口

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -q
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_dialogue --live
```

对话验收脚本使用独立临时数据库、合成问题、mock 检索，真实模型读取本机既有配置。
它验证一句话解释、连续类比、换话题表格、代码示例、翻译和未绑定项目讨论；
不验证真实外网检索质量。未传 `--live` 时仅为离线夹具，不证明回答质量。

本机真实模型 `deepseek-v4-flash` 已完成六类连续问答：均返回 answered，结构及
引文契约有效，未调用检索工具；输出实际包含连续类比、对比表格和 Python 代码。
但“8 行代码”实际给了 9 行（含空行），翻译仍将末尾“不要搜索”包含在译文内。
因此这是表达多样性与链路验证，不宣称所有格式约束或语义正确性已通过。

本次相关的 29 项核心回归全部通过。全量测试的功能断言通过，但在不同轮次出现
Windows TemporaryDirectory 清理的 WinError 145；全量命令非零退出，不能算全绿。
模型连通性验证同时发现并修复新版 Anthropic SDK 不接收 temperature 顶层参数的问题，
现在通过 extra_body 保持原有请求字段，并增加兼容测试。

新增单元测试覆盖直接回答、相关源选择、搜索与读取组合、失败保留、禁止工具、
调用预算、项目外发边界与灵活回答中的引文过滤。旧的主题切换测试继续验证
不把旧技术标签错误写入学习画像，只调整了“不必追问才能回复”的预期。

当前在线演示和旧 HTTP UI 没有接入 ConversationAgent；开启 DEMO_REPLAY 的界面
仍返回预置回放。请通过 `python -m lodestar chat` 测试此后端，不能用回放判断效果。

本次“今天 AI 最新进展”实测暴露旧研究流程忽略网页计划、使用原始中文查询、
缺少时钟而生成错误日期的问题。auto 时事问答现已进入对话循环，并注入带时区的
current_time；支持网页搜索与读取，DuckDuckGo 失败或空结果时尝试 Bing RSS。
搜索摘要不进入已读证据；网页事实沿用原文引用校验；来源日期由模型核对，
仍不等于自动证明每条都是今天发生。旧研究报告流程仅在显式 intent=research 使用。

时事请求仅允许有引文的 claim 和缺口 gap，不能把未引用新闻放入 background。
校验失败最多修复一次；仍不支持的陈述不交付，错误和初稿留在审计记录。
本轮 33 项针对性测试通过。原问题真实复测已能搜索并读取网页，但只获取到
近期二手报道，未确认当天新闻；部分模型引文仍校验失败，故不宣称新闻质量验收通过。

局限：auto 的方案路由仍有关键词规则；公共搜索端点可用性及新闻覆盖不保证；
模型仍可能违反细微长度要求或产生一般知识错误。没有引入自动模型判分来掩盖这些限制。

## 当前版本的用户反馈与待改进项

用户实际询问“关于 harness 有什么最新研究”时，回答没有充分结合 Agent 项目语境，
在读取失败后过早转向澄清 Harness.io 等含义，也没有充分扩展到 runtime、工具编排、
上下文管理和评测等相关研究方向。该体验问题尚未解决。
检索或读取失败不能推出“没有相关研究”；后续需评估上下文消歧、查询扩展和换来源策略。
本次同步保留的是可测试的迭代版本，不代表自主研究质量已经完成验收。
