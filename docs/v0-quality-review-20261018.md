## 固定 QF-1：available 与 delivered 必须分开

固定真值包括：A 最近 3 条窗口、60/100→72/100、平均输入 token 1000→800；B 外部存储每次取回 2 条、另一批任务 30/100→45/100；A 发表未知，B 有夹具内正式记录。不同任务集不可排名，输入 token 变化不等于总费用变化。片段未提供实验细节，不证明整篇没有做。

这些信息在 source-snapshot.json 中 **available**，不代表模型已经看到。工具型场景先给摘要，必须实际 read_paper / verify_paper 才能取得对应正文/发表观察；人工 human-facts.json 从不发送给模型。直接材料场景则把 A/B 正文作为输入，属于 **delivered**，无需猜测其是否“隐藏在工具之后”。

因此：

- 已取得正文后继续外推，属于材料理解/推断边界问题。
- 只拿到摘要、没有读正文，却断言整个来源无实验，是取证决策失败与范围外推；不是诚实的未知判断。
- 程序 all_observed_runs_completed 或 source-snapshot 存在，均不证明正文实际交付或语义完成。
- 合成材料可以包含确定的虚构实验数字。synthetic 只阻止将其当成现实研究证据，不推出“无实验”“无需读正文”或“核验必定无记录”。

## 最终代码冻结与学习召回修复

correct 现在兼容 schema 中已有的冗余 discussed / attempted / self_report，校验后丢弃该值，由宿主统一保存 self_report。非法掌握事件、未知 action、撤销的多余参数仍拒绝，并发保护、失败回滚及失效上下文退休均保留。不是让模型自行提升用户掌握。
