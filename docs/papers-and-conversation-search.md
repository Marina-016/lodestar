# 论文、知识与方法、对话搜索

2026-11-13

论文入口 `/papers` 独立于个人记忆。论文的全局阅读状态为待整理、待学、在学、已读、已归档；未绑定项目也能维护状态。项目相关性、采用决定和研究计划继续独立保留。

掌握自评为未评估、已了解、能理解、能讲清、能应用。它独立于阅读状态。关联的学习记录显示技术、方法、事件和原始依据；只有实际讲解、实现或应用表现作为历史掌握依据。助手讲解、收藏和阅读不会提升掌握程度。

本地论文索引汇集实际对话引用、有效学习记录的论文来源和项目推荐。未使用的搜索结果、代码围栏里的示例链接不纳入。arXiv 版本合并为同一篇论文，原始对话保留版本和来源。重新索引不覆盖手动修改的标题、关键词和学习状态；撤销学习记录后移除派生关键词与证据关联，保留已收藏论文。页面不下载 PDF，不调用模型，不自动查询引用指标。

研究收件箱 `/research` 默认展示全部来源，可按阅读状态筛选并进入论文详情。选择项目后继续使用该项目的推荐、订阅、阅读和验证记录。订阅与后台通知折叠显示。

`manage_paper` 是聊天中的论文收藏、待学和状态工具。工具说明要求“待会学”等论文阅读安排保存为论文状态，不能放入个人长期记忆；后台任务不能修改用户阅读状态和掌握自评。用户自评保留对应消息来源；工具可先列出已有论文再按 revision 修改。宿主不增加关键词意图路由。

搜索对话 `/history` 是独立页面。空查询展示最近对话；文字查询按字面匹配，可筛项目、对话、发言者和最近 7/30 天。结果为紧凑的文本片段与安全高亮。详情默认突出匹配消息，前后最多各两条上下文可展开，提供原消息跳转。搜索筛选与选中消息 URL 分开保存。模型使用的旧历史搜索接口与项目/退休上下文边界保持原有规则。

全局阅读状态支持 revision 冲突检测；资料编辑与状态变更在同一 SQLite 事务中保存。源索引和迁移不建立“用户已学会”的推断。旧错误待学记忆只对已核对的条目做一次性迁移，停用旧记忆并保留修订、来源及数据库备份，不删除历史。

验收备注：浏览器使用独立 mock 数据，覆盖状态保存后刷新、掌握筛选、全局收件箱、学习记录、搜索高亮、上下文与窄屏溢出。真实库已在 SQLite 备份后迁移已核对的两条待学记录；39 条有效论文学习记录与 70 篇本地论文来源关联，不重新核验论文内容。未运行真实模型。通用 mock 模型不会产生工具调用，因此 `eval_workspace --scenario workspace` 的任务分派/记忆语义断言未通过；这轮不以该脚本宣称真实模型的任务编排质量通过。具体新增流程由独立 HTTP/工具回归及浏览器交互验证。
