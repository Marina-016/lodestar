# 本地 Web 工作空间 · V0

更新：2026-10-26。当前为黑白、冷灰的极简研究工作台，连接真实 ConversationAgent；离线模式会明确标注。UI 使用独立 HTML/CSS/ES modules，HTTP 服务使用 Python 标准库。

## 使用

~~~powershell
.\.venv\Scripts\python.exe -m lodestar ui --port 8124 --no-browser
~~~

打开 http://127.0.0.1:8124/ 。首页、刷新和恢复不会调用模型。旧橙色界面使用 ui --legacy，独立保留旧回放能力。

- 主对话持续交流，也可说“分别派发 Harness 和 RAG 研究任务”。
- 任务中心查看各任务进度，进入任务继续对话；聊天和来源各自保存。
- 记忆中心管理个人、项目和任务事实，展开“我的学习”查看技术/方法证据并纠正、撤销。
- 当前上下文查看项目绑定、当前可用记忆，以及所选回答实际保存的范围快照。
- 新建或管理任务可选择项目；登记项目只存名称/描述，不扫描本地代码。
- 模型设置读取同服务目录，推理强度跟随模型能力；运行中的配置冻结，后续运行使用新设置。

左侧“项目”打开 `/projects`，“记忆”打开 `/memory`，不再只依赖对话旁的抽屉。管理页离开不会停止后台任务；回到对话可恢复运行，未发送问题以同标签页 sessionStorage 暂存，不自动发送。

## 项目与 Git 工作区

可手动登记目标/说明，或从 GitHub 仓库首页链接导入。导入保存分支、提交 SHA 和有界 README，同时在 Web 数据目录的 repositories 下建立独立、可编辑的 Git 工作区。可查看本地状态、最近 8 条提交，复制路径后在自己的编辑器中修改、手工提交。仅克隆所选分支最近 50 次历史；不运行仓库代码、安装依赖、展开子模块/LFS 或自动推送，自动操作关闭 hooks 和配置过滤器。

“安全拉取并同步资料”只允许干净工作区在记录分支上快进，拒绝覆盖未提交改动、切换分支或合并分叉。本地未推送提交可能比已保存的 GitHub README 更新，两者分别显示版本。网络/克隆失败可能保留已登记项目和部分本地目录；可以查看后手动重试，不自动删除现场。私有仓库使用服务端 GITHUB_TOKEN 或现有系统 Git 凭据，页面不接收密钥。

项目名称/说明与当前 README 快照分别授权，默认关闭；明确授权的说明按需作为背景，不算已核实的实现证据。README 保存最多 12000 字符，模型按需读最多 4000 字符；新快照撤回旧许可。导入不产生个人事实或用户学习事件，工作区文件不自动索引或外发。数据库备份不含 Git 工作区，需另行保护本地未推送提交。

## 长期记忆页

复用原有记忆库而非新建副本，按个人/项目/任务、项目归属和状态管理，每页 40 条，可搜索字面内容。详情展示来源对话链接（若保留来源消息 ID）、最近 40 次内容修订及截断说明。旧版历史没有完整范围/状态快照，不把它称为完整审计日志。学习证据有单独分类，概览最多 20 项，可按技术/方法搜索其余记录，仍支持纠正/撤销。

编辑和范围迁移同时处理旧、新受影响任务；相关任务运行时拒绝冲突修改，修订号防止旧表单覆盖新记录。停用可恢复；遗忘清除该条内容和修订正文，不能在记忆页撤回，也不清除聊天、备份或云端已收到的数据。

## 模型可用性

模型目录不是额度接口。候选项标明“最近可用”或“未验证”；只有同服务、同账户和相同推理/输出配置在最近 24 小时成功过，才可成为默认推荐。首页不探测模型、不发推理，仍可保留用户明确选择的未验证模型；已知失败配置不自动重试或关闭思考。新建独立任务继承主对话的模型与推理偏好，调用开关保持任务独立。

服务明确报告免费额度耗尽、模型不存在或不可用时，隐藏该账户下该模型。普通 HTTP 400/404/422 只隐藏对应请求配置，不声称是额度问题；429 限流、网络故障不作永久不可用判定。错误诊断只保留安全分类，不保存原始服务错误正文或密钥。旧版 400 没有账户指纹，只能作为原任务匹配配置的警告，不跨账户推断。

隐藏模型在设置底部折叠区可见；“重新允许尝试”只解除本地阻止并恢复“未验证”，不验证余额、不发模型请求。充值、额度重置或配置修复后需用户明确恢复；最近成功也不是未来免费或可用的保证。阿里官方的免费额度停止错误与普通 TPS/TPM 限流并不相同，参见 [免费额度说明](https://help.aliyun.com/en/model-studio/new-free-quota) 与 [错误码](https://help.aliyun.com/en/model-studio/error-code)。

任务共享个人记忆和学习身份，同项目共享项目事实，不自动共享完整聊天。停止主对话不会停止已派发子任务。归档不删除产物，也不暂停已开始运行；需要停止时使用该任务的停止按钮。

## 记忆与纠正

个人偏好跨任务使用，项目事实只在同项目使用，任务备注只在该任务使用。模型自动注入最多 20 条、8000 字符，必要时按需 read_memory。

编辑有修订校验。相关任务仍运行时，共享记忆修改会返回冲突，防止在途范围不一致。纠正、停用和遗忘后重建受影响任务的后续模型上下文；历史聊天仍可查看，但旧段落不自动再次带入模型。遗忘清理该事实修订正文，不清理聊天和备份，也无法撤回已发送给服务商的数据。

学习针对技术/方法，不针对整篇论文。后台读过的论文不是用户接触证据；后台不写个人记忆或学习事件。前台的讨论、尝试、自评附用户消息证据，普通记忆不成为 demonstrated 掌握。聊天和记忆中心均可纠正或撤销已有学习证据，纠正只保存自评，撤销后重新计算。聊天先读取现有证据 ID，再复用相同修改逻辑；相关其它任务仍在运行时需等待或停止后重试。

例如：“我只看过 ReAct 的思考与行动交替方法，没有实现，记住这个接触情况。”“纠正刚才的记录，我其实只看到了摘要。”“忘记刚才这条学习证据。”这些能力的工具/上下文离线测试已覆盖，真实模型能否准确选择和操作仍需逐项验收。

## 来源与运行

来源只展示所选回答正文实际引用的 HTTP(S) 链接；未引用的当轮结果放在折叠检索记录。代码中的链接不算引用。历史补证不使用未来消息，不合并明确不同的 arXiv 版本，未关联项明确标记。引用记录不代表事实或相关性已核实。

运行状态为 queued/running/completed/error，停止为 cancelling/cancelled。同任务串行，提交幂等，事件可恢复；重启将未完成运行标为 interrupted。模型流和只读联网工具的本地等待可快速中断，迟到文本和工具结果不会继续进入对话或触发后续动作。已发往服务商的请求可能继续到网络返回或超时；不保证撤回云端请求或计费。提交记忆、任务等已有副作用不会因停止而撤销。

重新生成会复用原问题，将该问题的旧回答正文退休并从对话、检索和后续模型历史中移除，最终只显示新回答。保留必要的消息 ID 和已确认操作回执，不撤销旧回答中已执行的记忆或任务操作；运行审计与历史备份不属于隐私擦除范围。

等待卡显示星光、轻量波纹、真实阶段与等待时长，不模拟完成百分比；超过较长等待时提供停止提示。错误以短卡片显示友好原因，诊断类型和 HTTP 状态可展开查看。每轮运行记录首字耗时与阶段时间；点点传输另记录响应头、首个推理片段和首个正文时间，不保存原始推理内容。

点点接口省略 `chat_template_kwargs.enable_thinking` 时默认开启思考。“服务默认”保留省略，“关闭思考”明确发送 false，“开启思考”发送 true；结构化提取发送 false。修复前误把 false 当作省略的可用性记录不会验证新版请求。

## 数据与迁移

数据位于被忽略的 workspace/web/web.db，和 CLI 数据分开。旧 Web 用户键迁移到 web:local，旧会话和 ID 保留；主空间旧备注变个人记忆，旧任务备注保留局部范围。升级前应通过 SQLite backup API 备份。数据库副本迁移验收见 [发布检查](v0-release-check.md)。

启动现先保留端口及数据目录进程锁，再备份已有数据库，最后执行迁移和中断恢复。相同目录不能换端口重复运行；锁文件会保留，由操作系统释放锁，不要通过删除锁文件绕过。每次成功启动已有数据库前会新增 backups/pre-start-*.db，备份失败不继续迁移；旧备份不自动清理，也可能包含后来已遗忘的信息。

使用 `ui --data-dir workspace/trial-web` 可在独立 Web 数据目录试用或演练恢复；默认目录不变，模型配置和凭据不因此隔离。只读检查和不覆盖的备份命令、恢复步骤见 [本地内测清单](v0-local-release-20261023.md)。正常退出会阻止新提交、请求停止活动运行并等待线程及客户端收尾后释放锁；阻塞网络请求可能仍需等超时，强制终止后只标中断，不自动重试。

写请求校验同源 Origin、Host 和页面 token，服务只监听 127.0.0.1。无公网账号系统。前端不持有模型密钥，不渲染任意原始 HTML；来源仅允许 HTTP(S)。

## 视觉与交互

正文保持纯白清晰，使用统一冷灰层级、阅读宽度、间距和控件状态。局部半透明只用于覆盖内容的工具栏和面板标题，遮罩轻微压暗，不模糊整页。链接和焦点使用蓝色，无绿色装饰。

手机使用抽屉导航；表格和代码内部滚动。支持 Escape、面板焦点返回、原生表单对话框及减少动画偏好。任务状态轮询不重新加载聊天或打断输入，仅在状态变化时更新列表。

## 回答中的图表

回答支持 Mermaid 流程图、层级图（mindmap）、时序图，以及状态图、类图和实体关系图。用户可以直接要求“画一张记忆检索流程图”；模型也可以在流程、分支或层级较复杂时选择画图。图表标为 AI 生成示意图，不能当作论文原图。

流式输出期间保留图表占位，回答结束后再绘制，避免半段语法反复渲染。图表支持放大、缩放、拖动画布、复制代码和 SVG/PNG 下载；语法错误时显示提示并展开原代码，不影响其余回答。暂不支持节点编辑。

渲染器随应用打包，在本机隔离 iframe 中运行，无需绘图 API 或 CDN。图表内容不能执行脚本、设置初始化指令或加载外部图片。单图最多 16000 字符、150 条边；复杂图建议拆分。

仅修改图表依赖时需要 Node.js 22.12+：运行 `npm ci --ignore-scripts`，再运行 `npm run build:diagrams`，一并保留生成的 bundle、LEGAL 和 notices 文件。正常启动 Python 应用无需 Node.js。可用 `python -m scripts.preview_diagrams` 在独立临时数据库验收三类图表和错误降级；`--live` 会额外调用当前配置的模型一次，不使用用户聊天记录。

## lolo 人设与个性化

默认[人设卡](../lodestar/agent/lolo-persona.md)随应用打包，作为前台对话的系统提示词加载；修改后需要重启服务。lolo 的定位是有萌系女生气质、亲近且有判断力的研究搭档：先听懂最新问题，闲聊自然简短，研究清楚可靠，颜文字和“喵”只作点缀。用户保存的称呼和语气偏好仍通过原有个人记忆召回，不复制成另一份配置，也不将任意记忆正文提升为系统指令。

对话携带当前模型标识，训练数据截止日期未知时明确标为未知；不靠人设编造能力或训练经历。提示词可以改善交流方式和纠错习惯，不代表底层模型推理能力得到升级。`python -m scripts.eval_lolo_persona --live` 可用虚构对话检查纠正指代、情绪回应、换例子解释和身份诚实性，会真实调用当前配置模型；它是定性验收，不是智能水平评分。

## 当前限制

论文资料支持按需查询 Semantic Scholar 和 OpenAlex 引用指标，包含来源、时间、失败状态与新论文观察提示；不自动联网或按引用数评定质量。操作入口和可选凭据见[论文引用影响力](paper-impact.md)。

最近 200 条消息可见，模型只使用有界近期历史。跨窗口记忆编辑、语义召回、选段分叉、永久后台通知和自动掌握判卷仍待开发。

公共引擎可能验证拦截，阿里官方搜索需当前核实免费额度后启用；参见 [接入说明](aliyun-web-search.md)。当前验收不调用收费模型，不把离线任务结果当作真实论文质量证明。

现有 Vercel 是旧回放部署。新版真实服务的公网认证、隔离、持久化和费用限额尚未验收；本地可试用不能等同公网发布完成。


## 10-27 研究工作流

点击回答引用可查看当时保存的证据片段；项目详情增加“文件读取许可”，预览并批准特定内容版本。研究收件箱 `/research` 可按项目收藏、订阅、阅读、评估、生成草案并维护独立的手工验证记录。`/history` 提供字面检索及原消息定位。

服务运行时可单独允许后台检查公开论文订阅，默认关闭；通知只保存在本机，成功且无变化时不通知。独立后台启动/状态/停止、实际请求数、恢复与未验收的登录自启说明见 [六项功能交付](v0-next-features-20261026.md)。
