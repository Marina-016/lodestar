## 本轮实际修复

1. **启动顺序**：原 serve 在绑定端口前构造 WebApp，因而会先迁移数据库、把活动运行改成 interrupted，再因端口失败退出。两条修改前回归明确复现。现在先保留端口，再取得数据库的操作系统文件锁，最后备份、迁移和恢复；同目录换端口也不能绕过。Windows 监听使用排他绑定，避免 SO_REUSEADDR 允许覆盖已有监听器。
2. **单实例锁**：使用 msvcrt / fcntl，无外部依赖。进程退出后由 OS 释放锁，锁文件保留；不能删除文件来绕过锁。仅保证通过 serve 启动的合作式本地实例；不阻止人为直接写 SQLite、绕过入口或在网络文件系统上操作。跨进程互斥和测试进程被终止后的释放已验证。
3. **备份**：已有数据库每次启动前用 SQLite backup API 创建 `backups/pre-start-*.db`，包含 WAL 中已提交数据，再做 integrity_check；失败不继续迁移。源库以只读连接打开，目标必须是新文件，失败仅清理本次未完成的快照。备份不是简单复制正在使用的 .db 文件。
4. **关机**：停止接受新提交，向活动运行发送合作式停止信号，等工作线程、客户端和数据库收尾后才释放锁。任务入队到线程启动失败持久化之间也受同一锁保护。已发送的阻塞网络调用可能仍需等原超时；不保证立即退出、撤回云端调用或自动重跑。
5. **HTTP 拒绝**：拒绝 POST 时原实现不读取正文便关闭连接。确定性测试确认 64000 字节正文全部未读；修复为仅排空长度声明有效、至多 100000 字节的正文，再返回 403。请求读取有超时，已授权半包请求返回 408。Host/Origin/token 规则未放宽，拒绝请求不解析 JSON、不调用工具。40 次大正文拒绝检查通过；没有证明所有历史 WinError10053 都由此导致或全部消失。
6. **独立目录**：`ui --data-dir` 隔离 Web 数据库、备份和锁，用于新用户试用及恢复演练；未指定时仍用 workspace/web。模型配置、.env 和论文缓存不因这个参数取得独立身份或新额度。SQLite WAL、SHM 和锁文件补入 .gitignore，避免自定义目录内的旁文件进入 Git。

宿主边界改动没有新增意图路由、固定研究模板、强制阅读篇数或反思 Agent；模型、搜索和费用开关保持原样。

## 本地试用与恢复

仅绑定 127.0.0.1。小范围内测指受邀用户各自在自己的本机运行，不是多人共用一个匿名公网/局域网入口。新版服务不能直接套用旧 Vercel 回放配置发布。

启动原工作空间：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m lodestar ui --port 8124 --no-browser
~~~

首次试用或安装包运行建议明确指定持久目录：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m lodestar ui --data-dir workspace/trial-web --port 8124 --no-browser
~~~

不要让实际用户数据依赖安装包目录的生命周期；不要通过改端口或删锁文件启动同一个库。先正常退出旧服务，观察任务停止和进程退出，再启动新版。

独立的只读检查、手动备份命令不加载 .env 或模型客户端，输出只有完整性与表计数，不输出记忆/消息内容：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m lodestar.web.maintenance check --database workspace/web/web.db
.\.venv\Scripts\python.exe -X utf8 -m lodestar.web.maintenance backup --database workspace/web/web.db --output workspace/backups/before-upgrade-20261023.db
~~~

目标文件已存在就拒绝，不覆盖、不自动换名；再次操作时显式选择新的目标。自动备份也包含个人数据和后来已遗忘的信息，不自动清理、不上传；须关注磁盘空间与自己的保留策略。备份不包含 .env、PDF 缓存及其他目录，也不能撤回云端已收到的数据。

恢复到全新目录检查，不覆盖原库：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m lodestar.web.maintenance backup --database workspace/backups/before-upgrade-20261023.db --output workspace/trial-restore-20261023/web.db
.\.venv\Scripts\python.exe -X utf8 -m lodestar ui --data-dir workspace/trial-restore-20261023 --port 8125 --no-browser
~~~

检查任务、消息、记忆数量与内容，再决定使用哪份库；恢复副本中的活动运行会标为 interrupted，不自动请求模型。演练时保持真实模型调用暂停。回滚到旧代码时，应保留当前库，再在独立目录使用对应的旧版备份；不要让旧代码直接写新版库。该方式不会合并升级后的新数据，不能当无损回滚。
