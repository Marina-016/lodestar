# Lodestar 对话、入口与本地笔记升级

2026-11-13。对应：研究入口持续可达、长对话与插话基础、Obsidian / 本地目录、减少界面说明。

## 体验

- 空对话保留三张开始卡片。有历史时，在输入框上方保留“推荐一篇论文 / 理解一个概念 / 探索项目思路”三个轻量入口；点击填入问题，不自动发送，也不会覆盖已编辑的草稿。
- 移除主对话的活动指标看板，收起装饰性眉题、重复的操作说明与上下文范围脚注。权限、费用、错误和文件冲突等决策信息仍保留。
- 发送和停止分开。生成中输入补充后发送，会先停下旧轮，再按最新问题接续。旧轮正文、来源和已执行动作保留；有后续问题的旧中断回答收成可展开记录。
- 项目页新增“连接本地”。可连接 Obsidian Vault 或普通 Markdown 目录，搜索标题/内容、查看、编辑、新建子目录笔记、另存为、在 Obsidian 打开。编辑草稿保留在本页及当前浏览器会话，切换笔记或关掉编辑窗口不直接丢失。

## 长对话与纠错

普通对话仍使用同一个模型自主工具循环，没有新增意图分类器或固定研究步骤。

- 直接近期窗口从 8 条扩到 24 条消息，仍有 24000 字符总预算；有选中参考文本时，历史预算继续收紧。
- 新增单会话 `update_conversation` 内部工具，由模型在需要时维护目标、约束、纠正、未完成问题和进展；支持 active/resolved/superseded，引用实际消息 ID。
- 工作状态最多带入 6000 字符；另补回有界的早期/相关用户请求，并附最近已提交动作回执，降低重讲、忘条件和重复副作用动作的风险。
- 工作状态与个人长期记忆分开。同会话校验来源；已删除消息、已退休上下文和其他任务不能成为有效锚点。最新用户纠正优先于旧状态，解决后的事项不应自动复活。
- 这些机制改善可用上下文与恢复能力，不代表模型每次都能正确提取约束或理解纠正。当前没有额外付费摘要调用，也没有自动把所有旧聊天变成事实。

## 生成中插话

补充内容先持久写入本地队列表，再触发旧运行的合作式取消；等待旧轮收尾后只启动一次新轮。

- 请求键去重；同空间最多一个待接续补充；普通发送不会抢占它。
- 补充继承原轮的外部检索限制。已提交的任务/记忆操作不自动回放；历史回执供模型查看。
- 停止会撤销尚未启动的补充。启动失败保留文本，允许重新填写；服务重启将未启动补充标为 interrupted，保留文本但不自动调用模型。
- 同空间仍保持一次一个运行；不同任务沿用原有并行机制。不是两个回答同时生成，也不保证已发出的网络请求可以立即撤回。

## 本地笔记边界

- 连接明确选择的本地目录，不扫描整个电脑。仅管理目录内 UTF-8 Markdown，单文件最多 200KB。
- 排除隐藏目录、Obsidian 配置、链接/重解析目录及越界路径。不处理附件、画布、Obsidian 属性语义或双链自动重命名。
- 保存采用内容版本校验和原子替换；外部修改后拒绝旧版本覆盖。替换前在 Web 数据目录的 `vault-backups/<项目ID>/` 留备份。
- 本地浏览和编辑不构成模型读取许可。模型继续只获得用户逐文件批准、版本仍一致的最多 4000 字符片段；保存/外部变化后旧文件授权失效。
- Obsidian 使用同一份本地文件；本轮没有替用户选择或修改真实 Vault。实际使用时，在“项目 → 连接本地”填写希望连接的目录。

依据：[Obsidian 数据存储](https://obsidian.md/help/data-storage)、[Obsidian URI](https://help.obsidian.md/Extending+Obsidian/Obsidian+URI)。本轮没有安装 Obsidian 插件或配置云同步。

## 验证

使用隔离数据库、目录和本地流式模型验证：推荐入口、插话与接续、刷新恢复、390px 窄屏、目录连接、笔记读取/新建/保存/内容搜索、草稿保留和 Obsidian URI 构造。

新增后端测试覆盖：长对话锚点、纠正与未完成状态、跨会话/已删除来源排除、插话幂等、停止撤销待接续内容、重启不自动发送、检索边界继承、文件版本冲突、授权失效、目录越界和备份。

真实模型的长期理解质量与真实 Vault 的个性化工作流尚未进行真人验收。浏览器验收没有调用真实模型，没有打开或修改用户真实 Obsidian 笔记。

最终结果：754 项 Python、63 项前端测试通过；Python 编译、JavaScript 语法、CSS 编译和 git diff --check 通过。原有数据启动前自动备份；本地 8124 服务已平滑加载新代码。
