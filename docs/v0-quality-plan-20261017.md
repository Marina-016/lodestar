# V0 质量版开发计划

更新：2026-10-17。开发基线：master `7d09636`；工作分支：`codex/v0-stability-20261017`。

## 目标

交付稳定可试用的本地单用户 V0：用户从主对话提出研究问题，模型自主检索与阅读论文、解释证据、推进两个独立任务，并结合授权项目材料给出待验证建议。保持简单的模型工具循环，不增加固定意图分类器、研究阶段模板或反思 Agent。

用户已授权持续开发与产品/测试/研发分工。日常实现、离线测试、公开论文检索及独立验收资料继续推进；只有费用、凭据、资料外发授权、公网发布或无法从现有意图判断的重要产品选择需要用户决策。

## 已有基线与缺口

- 已实现：白色 Web 工作台、主对话、并行任务、共享个人/限定项目/局部任务记忆、技术与方法学习证据、论文发现/阅读/发表核验、独立方案及实验后端。
- 10-15：334 项离线 Python 与 14 项前端通过；最新 master 的 GitHub CI 已通过。当前检查再次通过 14 项前端与语法检查。这些不代表真实模型研究语义达标。
- 真实验收仍失败：Harness 语境偏差、摘要外推、未知发表状态误写、比较引用遗漏、派发叙述与实际动作不一致、子任务流内错误。
- 环境限制：Windows WMI 查询曾卡住；普通启动可靠性未证明。流内错误已识别，服务端原因仍未知。

## 第一阶段：可靠运行（P0）

负责人：运行时研发、传输研发、测试。

1. 建立不改配置、不调用云模型、不污染用户数据库的修改前基线；卡住时取得有时限的栈证据。
2. 定位 Windows 初始化卡点，优先移除不必要的系统信息查询或使用局部、可维护的兼容路径；不全局替换 WMI，不降低证书校验。
3. 明确物理模型请求尝试；避免 SDK 隐藏重试与应用预算不一致。对错误进行安全分类，保留部分文字和已完成工具动作。
4. 复现分片流、数据型错误、空流、取消/刷新/重启，以及任务提交后父运行失败。只修复有证据的缺陷，不用笼统重试掩盖服务故障。

放行：无 API 离线回归通过；正常初始化可重复完成；请求数与故障分类可核对；取消和刷新不重复动作。服务端真实错误是否恢复单独记录，不由本地单测代替。

## 第二阶段：研究回答质量（P0）

负责人：产品、测试、主研发。

以 [八组质量验收卡](v0-quality-cases.md) 为执行入口。先固定来源证据核对 harness 传递和持久化，再在核实当前免费额度后进行小规模真实模型检查。每个输出分开登记功能状态与人工语义结论。

重点：当前语境下的 Harness 含义、近日期依据、摘要/正文边界、方法/实验比较、未知发表状态、数字推导、可点击且支持结论的引用，以及精简追问后事实保持。

放行：八组场景有实际证据与人工结论；易错场景用另一种自然说法复核。明确证据不足可以通过，编造、虚假动作完成及越界记忆不能通过。不得按字数、标题数量、非空或模型自评分判质量通过。

## 第三阶段：双任务与项目建议闭环（P0/P1）

负责人：Web 研发、测试、产品。

- 主对话实际派发两个任务，子任务保存各自语境、约束、模型配置及来源；共享适用个人/项目记忆，不自动广播全部聊天。
- 父空间读取真实子任务结果再汇总；提交、运行、失败、取消和完成保持区别。
- 验证个人共享、跨项目隔离、任务局部、学习纠正及遗忘后的上下文失效。后台阅读不增加用户掌握或接触事实。
- 只依据明确授权的有界项目材料给方案与最小可区分实验；区分事实、推断、草案和实际执行。普通 Web 聊天不自动运行生成代码。

放行：整轮派发、分别完成/失败、主空间汇总和记忆纠正均可恢复、可核对；不存在靠文字声称成功替代真实动作的产品展示。

## 后续顺序

1. 可靠通用网页检索（P1）：不阻塞论文主路径；公共引擎失败明确返回；官方 MCP 仅在核实账号当前免费剩余次数并登记后使用，不自动付费回退。
2. 长期历史召回、持久后台与通知（P2）：另做范围、版本、恢复和资源预算设计，不把进程线程视为永久服务。
3. 公网版本（P3）：认证、用户归属、HTTPS、限流、备份与恢复、费用控制，以及真实研究质量门通过后再发布。

当前不新增 UI 重做、选段分叉、无痕身份、自动掌握评分或自动采用方案。必要变更以可验证用户收益和失败证据为依据。

## 工作与报告约定

- 各研发子任务有独立文件所有权，主 agent 汇总审查；不让多个 agent 同时改同一文件。
- 每个能力改动配针对真实风险的测试，保留失败记录。离线夹具、真实模型、公开检索和浏览器验收明确区分。
- 用户数据库、凭据、缓存和原始真实运行资料不进入 Git。公开资料与离线夹具在独立验收目录运行。
- 模型目录存在不等于免费或可推理。10-14/10-15 的额度记录不当作今天余额；未经当前核实不开展可能收费的真实调用。
- 不静默切换模型、扩大文件外发、重放有副作用动作或降低测试断言。
- 提供阶段交付、验证范围、剩余问题与下一步；无重要变化时不重复通知。任务受阻时继续推进不依赖该条件的工作。
