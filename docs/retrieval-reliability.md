# 论文检索可靠性

2026-10-09：修复普通对话中论文查询超时、限流与跨轮读取路径。普通导读已进一步简化，见 [对话 Harness](dialogue-harness.md)。

## 模型与工具的职责

模型理解用户，选择关键词/字段表达式、来源、日期范围、排序及阅读深度。
search_papers 的纯词项用显式 AND 连接，带引号的短语保留；显式 arXiv 字段/布尔语法原样传递。
日期通过 days 编译为 submittedDate 区间，不能靠查询中的年份或 recent 一词过滤。
discover_papers recent 默认浏览 cs.AI，也可传模型指定查询；trending 使用 HF 平台热门数据，
不是全网热度、不是指定提交时间窗。阅读默认摘要，模型可选择 full_text=true。

候选标题、日期、链接可直接列出。候选保存在当前用户会话消息元数据中，跨轮/重启可读取，
但不会变成已读论文或学习方法证据。只有实际读取的内容能支持引用和方法接触提取。
无效摘要被过滤时仍可交付可核对的候选元数据。来源候选不代表已验证当前事件。

## 共享 arXiv 客户端

搜索、近期发现和摘要 API 共用 tools/arxiv_client.py。
默认本地状态路径 workspace/arxiv-client/metadata.sqlite，可用 LODESTAR_ARXIV_CACHE_DIR 指定。
SQLite 事务在缓存未命中时覆盖等待和 HTTP 请求，协调本机相同状态目录中的多个终端：
一次一个在途请求，启动间隔至少 3.1 秒。其他设备/独立状态目录不会由此协调。

成功 Atom 元数据缓存 15 分钟；命中保留原抓取时间和 cache_hit，不伪装成刚检索。
429/5xx 遵循 Retry-After（秒数或 HTTP 日期），缺失时冷却60秒；超时/连接失败冷却10秒。
冷却期间仍可取有效缓存，不再访问该 API。没有内部无限重试，不更换IP绕过限流。
失败不缓存成空结果；有效空结果可以缓存。日志记录最后200次网络请求的参数、状态和耗时。
PDF已有独立缓存，本客户端存的是元数据，不是论文全文。

工具决策的 JSON 对象调用启用阿里官方 response_format=json_object。
普通回答直接生成 Markdown，不再要求 blocks 或逐字引文。完整摘要供导读；学习记忆、方案和实验各自校验。
不是增加语言关键词路由，不改变用户掌握判定或项目文件外发权限。

## 验证

覆盖缓存跨实例共享、并发间隔/串行、429冷却、超时后缓存可用、错误不缓存、HTTP日期、
查询 AND/短语、真实日期条件、统一摘要客户端、候选跨轮读取以及 JSON 模式范围。
真实工具测试：近7天 cs.AI 返回3篇（首次2.31秒，重复0.02秒）；HF返回3篇；摘要读取成功。
实际客户端日志前10次网络请求均200，最小启动间隔3.563秒。

真实对话原问题成功列出4篇论文；近一周Agent查询用days=7，成功列出4篇日期和链接。
追问成功选中并读到第二篇摘要，但一轮模型回答接口超时（45秒测试超时设置），
不应把它归因于 arXiv 或把整条真实连续对话说成无条件稳定。
