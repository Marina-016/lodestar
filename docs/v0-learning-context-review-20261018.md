# 学习证据模型上下文限制 · 2026-10-18

本轮给学习资料的模型视图增加字符预算，覆盖主对话自动注入、read_memory、纠正/撤销后的上下文重置与旧研究综合入口。数据库及记忆中心仍保留完整原文，未改变掌握计算、默认模型或SYSTEM。真实模型与外网请求新增均为0。

## 复现与修复

原来只限制组数和每组证据条数，单条证据仍可能很长。新增测试实际测得自动证据包130256字符、显式读取23496字符、纠正回执21546字符；这些不是模型token计费数。

新增 learning.model_context 在模型边界限制序列化 profiles JSON 的长度，默认12000字符，计入JSON转义、字段、列表和分隔符。预算覆盖该学习列表；coverage说明、其他工具结果、当前用户消息、历史和来源各有自己的范围，不能把它说成整个请求、字节数、token数或云端账单上限。

小资料列表原样保留。超限时先保留技术/方法身份、事件计数、掌握状态、较早的掌握依据引用及最近证据引用，再按空间保留完整证据字符串和关联论文。单条证据放不下时不切半句、不生成摘要，改为明确的正文省略引用：

- id、event、actor及来源链接等保留可容纳的结构信息。
- evidence为空字符串且 evidence_omitted=true，evidence_original_chars记录存储字符串长度；这不表示原始证据为空。
- 已保存JSON中的message_id和corrects链接分别保留为source_message_id、corrects_evidence_id；仅保留已有记录，不宣称重新核验了来源内容。
- context_truncated、profiles_omitted与evidence_texts_omitted披露投影范围；证据条数截断和正文省略分别表达。

mastery仍由完整有效历史决定，不由投影生成或升级；旧证明正文太长时仍保留其ID。撤销后的下一次投影重新基于有效事件，失效证明不会继续决定掌握状态。空间太小时允许省略整个方法组并报告数量，不伪造unknown来替代不可见记录。

read_memory的实际返回组数及learning_profiles_truncated按预算后的列表重新计算。学习事件/匹配总数仍来自同一读快照，用户与项目/任务范围规则保持不变。模型应根据省略标记区分“没有收到正文”和“原始记录没有内容”，不能把引用当完整阅读证据。

## 验证

修改前6项召回、24项证据包测试通过。新增7项回归覆盖自动上下文、JSON转义及极小预算、较早掌握依据与撤销、小记录原样保留、旧综合提示、显式工具读取、预算耗尽后的最终回答以及长纠正消息的真实来源绑定。相关21项Web记忆、6项召回、6项学习生命周期和24项证据包测试均通过，未放宽原有断言。

本机HTTP验收使用全新数据库及脚本模型，在独立合成来源任务中保存长用户消息并关联学习事件。主对话通过实际read_memory读取，23093字符的存储证据变为470字符的学习列表；完整原文未进入该次模型载荷，UI原文与实际source_message_id保留。socket只允许回环地址，外网和云模型请求均为0。报告范围是宿主交付和数据不变性，semantic_review仍为pending。

产物在被Git忽略的workspace/acceptance/learning-context-review-20261018-v1/：http-context-report.json、offline-regression.txt和validation-state.json。后者保存代码与既有账本哈希，复核前后不变。

最终457项Python离线回归通过（117.942秒），14项前端、Python/前端语法及依赖检查通过，发布预检327文件通过，零失败/错误/跳过。源代码与预算账本哈希在验证前后不变；本轮未复现此前间歇性HTTP中止，仍不宣称其根因已修复。

## 限制与后续

这是一层有界模型视图，不是语义总结。长证据正文可能整条省略；记忆中心仍可查看原文，当前没有新增按证据ID分段读取全文的工具。不能用省略后的视图评估完整原话的含义，也不能据此宣称真实模型会正确解释范围或完成Q07。

本轮不减少或重置历史模型请求账本，不把本地字符预算当免费额度保护。真实论文取证、连续学习语义、项目隔离与简洁忠实汇总仍按质量卡待验。此前间歇性HTTP连接中止继续保留历史记录，不因本轮功能检查通过宣布根因已解决。
