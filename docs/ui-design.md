# Lodestar 界面约定

2026-11-12。适用于主对话、独立任务、项目、记忆与资料、研究收件箱和搜索对话。

## 视觉基础

保留白色阅读画布、浅灰导航和 Lolo。正文优先，重点色只强调可操作入口、链接和当前选择；角色不替代运行状态。用户已有的重点色和消息气泡偏好继续生效。

| 元素 | 规则 |
| --- | --- |
| 文字 | 系统中文无衬线字体；页面标题 28px，详情标题 22px，正文 13–15px，辅助说明 12px |
| 色彩 | 正文 `--ink`，辅助 `--secondary`/`--muted`，背景 `--surface`，交互 `--accent` |
| 危险操作 | `--danger` / `--danger-soft`；“遗忘”和删除需表达后果，不使用普通主按钮视觉 |
| 间距 | 控件内 7–12px，动作组 8–10px，区块 18–24px |
| 形状 | 普通控件 10px 圆角，功能分组 14px；引用标签可用胶囊形 |
| 工作表面 | 筛选栏浅灰底，输入框白底；列表用重点色选中条；空状态用轻虚线与明确下一步 |

## 操作层级

- `.primary`：当前区域的主要动作，例如新建、保存、收藏、搜索。尊重用户配色。
- `.secondary`：编辑、取消、关联入口，白底细描边，与主要动作区分。
- `.subtle`：刷新、展开、次级管理动作；保留可见文字和点击区域。
- `.icon-button`：紧凑工具；提供 `aria-label`，手机点击范围至少 40px。
- 按钮与按钮式链接使用相同尺寸、字体和垂直对齐方式。运行中按钮显示禁用状态。

## 命名与页面职责

- **主对话**：连续提问、引用材料、查看来源与运行回执。
- **任务**：持续跟进的独立研究课题，保留自己的设置和记录。
- **项目**：目标、工作区、资料许可及关联任务。
- **记忆与资料**：论文、全部记忆、个人/项目/任务记忆及学习证据。资料保存不等于模型阅读。
- **研究收件箱**：以项目为范围管理候选论文、订阅、阅读证据、方案和验证记录。
- **搜索对话**：按原词找回历史消息；保留项目与查询条件，清空查询后清空旧结果。

## 状态与反馈

- 空列表说明为什么为空，以及可采取的下一步。没有项目时，研究操作禁用，并提供项目入口。
- 保存时禁用本次表单、显示“正在保存…”，阻止重复提交；完成或失败后恢复控件。
- 保存尚未结束时不允许关闭弹窗。错误显示在弹窗内部，避免被原生 dialog 顶层遮住。
- 成功提示与错误提示分开；失败不声称保存、阅读或执行成功。
- 来源、订阅联网和模型调用继续保留实际行为说明。
- 详情请求使用版本检查，避免快速切换项目或结果后显示旧请求的数据。

## 响应式与键盘

- 宽屏显示列表与详情两栏；窄屏上下排列。打开详情自动定位，提供“返回列表”。
- 手机表单按“标签 → 对应控件”排列，避免双列表单塌成“标签 → 标签 → 控件”。
- 手机导航包含可见链接及按钮的完整焦点循环，Escape/遮罩关闭后焦点回到菜单按钮。
- 原生 dialog 管理焦点；保留键盘焦点轮廓、减少动态效果偏好和强制颜色支持。

## 验证范围

本轮使用独立数据库、离线模式及禁用模型的测试服务。浏览器验证覆盖任务创建、外观配色、项目创建与详情、记忆保存、论文分类切换与刷新、论文保存、研究详情、手工验证记录、订阅保存、历史搜索/刷新/清空、提交防重及弹窗内错误、手机导航与表单顺序、五个主要页面无横向溢出、手机详情返回列表。

真实模型生成、外部检索、真实 GitHub 导入/拉取、代码文件授权以及桌面宠物启动未在本轮重新执行；这些入口保留原有服务和权限语义。本轮不以离线 UI 验证代表外部服务或研究质量验收。

验证结果：63 项前端回归、84 项相关后端回归通过；四个改动模块语法检查与 `git diff --check` 通过；发布检查扫描 332 个候选文件，未发现疑似密钥。
