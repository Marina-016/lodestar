# Lodestar v0 Demo 视频脚本

## 一句话主题

Lodestar 把一个模糊的学术问题，变成有证据、有记忆、可验证的下一步。

## 视频目标

这不是一个”AI 搜索框”演示，而是展示一条完整的研究闭环：

```text
提出问题 → Agent 选择研究路径 → 检索与综合证据 → 对比”新在哪里” → 更新个人知识 → 生成可验证实验
```

它体现 AI 产品经理的四项能力：问题定义、Agent 工作流设计、知识状态设计，以及从洞察到验证的产品闭环。

**核心差异点（镜头要服务这句话）**：Lodestar 不是摘要器，而是持续回答 **”这次相比我已经知道的，新在哪里”**。步骤 3 的”新在哪里”对比、步骤 4 的”写入个人知识状态”是两个必须被拍到的落点。

## 第一版录制范围

- 时长：60–75 秒
- 画面：16:9，只录 Lodestar 内容区，不录浏览器标签栏和大面积空白
- 第一版：无字幕、无配音、无额外动效
- 录制时展示可观察的 Agent 工作过程，不展示模型内部隐藏推理

## 录制脚本

### 1. 从一个问题开始（0–6 秒）

画面停留在“研究对话”首页，在输入框输入：

> 帮我研究本周 Agent Memory 的学术热点：找出最值得关注的一条，解释它对 Lodestar 的启发，并给出一个可验证实验。

点击发送后停留片刻，让观众看到问题是从对话框进入研究流程的。

### 2. Agent 开始研究（6–16 秒）

保持在研究进度状态，展示：理解问题、选择研究路径、检索来源、记录研究步骤。

这里表达的是 Agent 的外显工作流，而不是模型的隐藏思维过程。

### 3. 生成研究结论（16–30 秒）

展示核心结论、Why it matters、与 Lodestar 的关联，然后**向下滚动时在"新在哪里"两处各停留约 2 秒**：
- `What is actually new`（本次新增：Agent Memory 分层化 episodic/semantic/procedural 与 evaluation 反馈驱动的 memory updating）
- `Connection to My Knowledge`（"本次研究前你已掌握 Agent Memory…，Memory Updating 是已有概念 Memory 的延伸"）

让观众直观看到"相比我已经知道的，真正新的是什么"。随后快速滑过 Evidence Trail、论文来源和 PDF/预印本信息，不做过长停留。

### 4. 把理解写入知识库（30–42 秒）

滚动到”把这次理解留在 Knowledge State”，点击”记住选中的结论”，等待”已更新知识”，再进入”知识库”页面，展示 Agent Memory 概念已经进入个人知识状态。

**录制提示**：在”记住选中的结论”点击前，旁白补一句点题——“它给我的不只是几篇链接，而是告诉我：这次相比我已经知道的，真正新的是什么”（与视频目标里的核心差异点呼应）。

### 5. 从知识到实验（42–58 秒）

进入”实验项目”，找到”带反思的 Knowledge State 是否能减少重复检索？”，点击”生成骨架”，展示实验从 draft 变成 built，以及生成后的实验标题、假设和基础结构。

**旁白注意**：这里”生成骨架”是确定性 scaffold（假设文档 + A/B eval harness 模板），**不要旁白说成”自动把实验跑完”**——真实完成 baseline/candidate 需要 coding agent（codex/claude）继续实现。若时长允许，可补一句：”骨架生成后，Lodestar 可以继续交给 coding agent 实现 baseline 与 candidate，完成 A/B 实验闭环”。

### 6. 结尾画面（58–75 秒）

停留在已生成的实验骨架页面（收住"闭环感"），然后**切到"实验项目"列表**，展示一条已 `built` 的实验（如"独立的 Skill selector credit 是否提升长任务成功率？"），体现"研究判断 → 可验证实验"的闭环积累。最后让观众记住：

```text
热点发现 → 证据理解 → 认知更新 → 实验验证
```

> **说明**：本产品**没有独立的"选题"页面**——选题就是对话框里的自然提问（本脚本第 1 步的提问即是一次选题，研究结论本身回答"本周什么值得关注"）。`frontier`（Weekly AI Frontier 选题推荐）以 CLI 命令提供，不进入 UI 演示。

## 后期旁白草稿

> 我不想只让 AI 告诉我一个答案，我希望它能帮我完成一次真正的研究。
>
> Lodestar 会先理解我的问题，再选择研究路径，检索相关论文和资料，并把结果和我正在做的项目联系起来。
>
> 它给我的不只是几篇链接，而是告诉我这个方向为什么重要，哪些是共识，哪些才是真正的新变化。
>
> 当它发现一条值得长期保留的新知，我会把它写进我的知识状态。下一次研究时，Agent 不再从零开始，它知道我掌握了什么、缺什么。
>
> 更重要的是，研究结果不会停留在笔记里。Lodestar 会把一个研究判断转成可以验证的实验——先固定 baseline 和评估指标，再比较 candidate。
>
> 它不是简单的"问答——答案就结束"。每一步研究都会沉淀下来：值得保留的结论进知识库，可验证的判断变成实验，下一次我可以从这些积累上继续。这不是一个会聊天的搜索框，而是一位研究搭档：帮助我发现问题、理解证据、更新认知，并验证判断。
