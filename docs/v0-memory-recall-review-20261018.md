## 可复现缺陷与修复

旧 recall 按大小写敏感的 DISTINCT 枚举技术/方法，但 profile 按 SQLite NOCASE 分组；同一组的 ReAct/react/REACT 可能重复返回并占用结果名额。现在检索、统计与资料投影共用同一 NOCASE 身份规则，不修改已保存事件。

旧 recall 先找到匹配方法，再读取该技术最多500个最近方法，从中筛选目标。某技术有501个更新方法时，即使搜索准确命中较早方法，也可能返回空。现在先在全部有效方法名称中匹配和排序，再直接投影选中的方法，不套用无关的展示上限；同分匹配优先较新的有效记录。profile 的展示数量上限仍保持原有行为。

掌握程度、关联论文和历史证明仍从该组完整有效事件计算，近期证据只做有界展示。新增 evidence_truncated 明确证据列表是否完整；旧掌握依据仍通过 mastery_evidence 单独保留，撤销后重新计算，不因读取或近期自评自动升级掌握。

## 模型读取的范围说明

read_memory 保持原有数据归属、词法匹配和数量/备注字符限制，不自动把无匹配改成全库回退。结果新增：

| 字段 | 含义 |
|---|---|
| user_active_learning_profiles | 当前用户有效的不同技术/方法组数量，不是事件条数 |
| matching_learning_profiles | 应用当前技术/方法名称过滤后匹配的组数 |
| learning_profiles_truncated | 匹配组因返回数量限制而省略 |
| matching_memories | 当前空间可见、有效、过滤后匹配的备注数 |
| memories_truncated | 匹配备注因数量或字符预算而省略 |
| filter_fields | 备注搜索 content；学习搜索 technology/method，不声称搜索了所有证据正文 |

原有事件计数和返回数量保留。计数、匹配和返回值都在同一 SQLite 读取快照内计算；其他用户、不可见项目和任务备注不进入可见计数。概览仍可能截断，不能把有界概览说成完整档案；查询无匹配也不表示所有已保存记录为空。

本轮界定的是记录数量及展示范围，没有给学习证据正文新增总字符预算，也没有新增按任意偏移翻页工具。显示被截断时可用已有明确技术/方法查询缩小范围，但当前词法检索不等同于语义检索。
