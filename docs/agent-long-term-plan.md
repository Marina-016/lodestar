接下来的顺序：

1. 在隔离用户/数据库中验收真实追问讲解及方法接触，核对来源和掌握状态。
2. 新运行的环境版本与精确包清单已实现并实际复核；继续核对本地复跑、输出复核与远端模型重新采样的保证。
3. 完成全目标证据表，按不足项继续修复，核对 PRD、架构、CLI 和运行手册。
4. 只有证据证明当前后端目标完整交付才结束长期目标；否则保留具体待验收项。

持续遵守：默认模型调用关闭，仅启用已核对免费且用完即停的 qwen3.8-flash；远端本地项目数据只限用户批准三个文件片段。研究结果不自动变成采用决定或用户掌握。不自动执行模型生成的代码，不改真实用户库。

后续扩展单独规划：独立项目任务与来源语义标注集、统计重复实验、生产上下文策略选择、永久后台/通知、学习表现判卷、技术别名/语义召回、UI。当前失败、no_change、uncertain 和负面实验都是合法研究结果，但不能据此宣称未做的扩展已经完成。
