# V0 六项功能交付 · 2026-10-26—27

用户确认按顺序完成论文证据查看器、项目文件授权与检索、项目研究收件箱、历史检索、方案与实验记录页、本地后台与通知。本轮六项本地功能均已实现并完成离线验证；模型自主研究的语义质量仍未放行，未发布公网，未恢复此前关闭的 Codex 定时开发计划。

## 入口与完成范围

| 功能 | 使用方式与边界 |
|---|---|
| 论文证据查看器 | 点击回答内引用，或打开“来源与上下文”，查看已保存片段、查询、章节、明确论文版本、抽取坐标与省略标记。区分逐段正文/摘要；未来消息不能追溯改变旧回答证据。只保存元数据的旧记录明确显示没有原文，不重新联网。证据段数不充当物理读取次数。 |
| 项目文件授权与检索 | 项目详情→文件读取许可→本地预览→批准当前片段。仅支持管理工作区内已跟踪的有界 UTF-8 文本，排除链接/路径逃逸、常见凭据路径、二进制及过大文件。每项目最多50文件，每文件交付最多4000字符；按查询选取，整个项目材料仍有数量上限。许可绑定内容摘要与 Git HEAD，任何一项变化或撤销后旧快照不再交付。旧环境级文件白名单保留，用户库没有被预先授权。 |
| 研究收件箱 | `/research`，也可从项目详情进入。收藏 arXiv 论文，区分待读/已读状态/忽略与实际阅读证据；管理公开查询订阅，按需检查并阅读。复用既有订阅、阅读、评估与方案记录，Web 与旧 CLI 数据仍隔离。一次操作只涉及选定项目。 |
| 历史检索与引用 | `/history`，字面检索、项目筛选、每页20条，查看原消息并返回所属对话；不依赖前端最近200条列表。新增模型工具 search_history 仅搜索当前任务或同项目、非退休的历史，返回有界片段与消息链接。用户界面仍可查看其保留聊天；历史助手回答不是已核实来源。未实现向量或别名语义召回。 |
| 方案与实验记录 | 论文详情内可发起适用性评估及方案草案，或手工记录假设、基线、验证方法、结果与采用决定。模型评估最多1次请求，草案最多2次（含一次结构修正），运行冻结主对话配置，调用暂停与已知不可用模型会阻止入队。缺少已读论文/授权材料时不构造模型客户端。既有模型草案、实际实验/调查关联与用户手记分开展示；网页不执行代码，手记不作为系统执行证明或学习掌握。 |
| 本地后台与通知 | 独立进程控制 start/status/stop，服务关闭页面后仍可运行；按数据目录互斥并继续启动前备份。订阅检查独立开关默认关闭，约30秒查看到期项目，只用公开检索、不调用模型。完成/失败/中断与新增候选保存本地通知，已读持久化，重复事件去重，无变化的成功订阅检查保持安静。 |

研究操作有持久 queued/running/terminal 回执及请求标识去重；同步、授权变更、聊天与同项目研究操作互斥。线程构造/启动失败保留尝试并释放占位。重启将未完成操作标为 interrupted 并通知，不重放模型请求；已保存产物保留。当前网络调用可能须等原超时，不承诺即时取消研究读取。原聊天停止/取消逻辑保持。

文件授权变化后，既有适用性评估会失效，不能据旧评估继续生成方案；README 快照和旧索引文档同样验证版本与权限。匹配和引用结构通过不等于建议有收益。

## 后台使用

先正常退出占用同一数据目录的前台实例；改端口不能绕过同库互斥。未创建系统登录任务，真实模型和订阅检查不会因本轮交付被自动开启。

```powershell
.\.venv\Scripts\python.exe -m lodestar background start --data-dir workspace/web --port 8124
.\.venv\Scripts\python.exe -m lodestar background status --data-dir workspace/web
.\.venv\Scripts\python.exe -m lodestar background stop --data-dir workspace/web
```

start 使用独立隐藏进程，status 只返回受核对的实例状态；stop 通过实例标识与本机 token 请求正常关闭，不按任意 PID 强杀。后台控制文件含本地控制 token，已加入忽略规则，不能共享；日志、数据库和 Git 工作区也不进入发布集。

可选 Windows 登录自启提供 autostart-on / autostart-off，同样须显式指定数据目录和端口；本轮没有安装。登录任务为当前用户 InteractiveToken 和最小权限，不是未登录时运行的系统服务。纯 XML 结构与转义检查通过，实际注册/登录触发仍未验收。曾尝试以 TASK_VALIDATE_ONLY 校验，但自动审批担心创建持久系统任务而拒绝；没有绕过，改用纯解析。官方标志说明见 [TaskFolder.RegisterTask](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskfolder-registertask)。

后台进程仍受计算机开关机、休眠和用户登录会话影响；站内通知不等于邮件、飞书或操作系统推送。关闭后台检查不取消已经入队的只读检索。停止后台服务不删除订阅和通知。
