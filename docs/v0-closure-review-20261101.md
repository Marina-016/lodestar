## 发现与修复

1. 学习工具首次只写技术名，遗漏明确的方法；加入字段说明后，又把“仅看摘要”拼入方法名。最终明确方法身份与接触程度分开，纠正时除非用户改名否则保留原方法；五轮真实复测通过。不做关键词抽取或自动补造方法事实。
2. 用户明确给出的 arXiv URL 未进入允许读取的来源集合。模型尝试读正文被宿主拒绝，重复消耗操作预算后退回通用知识。现在仅当前用户消息中的官方 HTTPS arXiv abs/pdf 链接进入 metadata 候选，可规范化 PDF 链接后按需阅读；不会据此声称已经读取。任意模型编造链接、仅助手历史出现的链接、相似域名和额外路径继续拒绝；后台禁止联网仍优先。
3. 项目工具说明明确只返回获准的本地材料，不把空 papers 数组解释成论文证据不存在，也不把项目配置当测量结果。
4. 新增 `project` 隔离 HTTP 场景、真实模型载荷记录及来源版本/授权撤销检查，支持 `--source-packet` 冻结公开论文。论文检查要求实际读到所有请求论文的非空正文；未读正文的流畅回答不能通过。参考答案不注入模型，语义报告保持 pending，另由人工审阅。
5. 原 workspace 场景补充父对话实际读取两个任务以及汇总未重新研究的检查；原学习场景补充方法身份保留检查。
