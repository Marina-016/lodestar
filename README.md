# Lodestar · Agent Research Lab

面向 AI 从业者的个人论文研究工作台：发现论文、连续讲解、维护技术与方法的学习证据，并结合项目形成技术方案与实验草案。

当前版本：**V0 / 0.5.0**。主入口是极简白色本地 Web 工作空间。模型自主理解问题和选择工具，宿主负责数据范围、运行状态、来源记录和费用边界。

## 现在能做什么

- **主对话**：持续交流，用自然语言委派多个研究任务。
- **项目页**：维护目标、说明、状态及关联任务；从 GitHub 建立真实本地 Git 工作区，查看分支、提交和未提交状态，按需安全拉取。
- **任务**：各自保存聊天、来源、运行进度和模型设置；可以同时推进、单独停止、完成和归档。
- **共享记忆**：同一个用户身份，个人偏好跨任务共享；项目事实仅在绑定项目内使用；任务备注保持局部。
- **独立记忆页**：按个人/项目/任务筛选、搜索和分页；编辑、停用、恢复、遗忘，查看内容修订与来源；学习证据单独维护，支持纠正自评或撤销证据。Web 聊天仍操作同一套记忆。
- **论文研究**：arXiv 检索、HF 热门信号、论文阅读、连续追问，以及已存在的项目适用性与实验后端。
- **研究收件箱**：收藏论文、管理公开查询订阅、按项目阅读证据和发起适用性评估；方案/验证记录与采用决定分开保存。
- **历史检索**：按原词和项目找回旧消息，模型按当前任务/项目与有效上下文范围按需检索。
- **证据查看器**：点击回答引用，查看当时保存的正文/摘要片段、版本与截断范围。
- **模型设置**：同服务模型目录与随模型变化的推理选项；运行开始时冻结配置。

已确认免费额度耗尽或模型不存在的项目会从候选列表隐藏，可在折叠区手动恢复尝试。默认优先最近 24 小时同服务、同账户及相同请求配置成功的模型；不会打断运行、覆盖仍未失败的手动选择或自动发请求。目录里的“未验证”不代表有免费余额，普通限流也不判定为额度耗尽。新建独立任务沿用主对话的模型与推理偏好，不回到过期的环境默认项。

可以输入：

> 分别建两个任务，研究 Harness 和 RAG 的近期论文。结合当前项目给出值得验证的方法，先不要改代码。

后台任务共享相关记忆，但不会自动读取其他任务的全部对话。主对话可按需读取任务结果。**后台读过论文，不代表用户接触或掌握了论文方法。** 学习围绕技术、知识点和方法记录，论文只作为关联来源；概念定义由模型组织，不保存成个人学习事实。

项目、记忆、研究收件箱和历史检索分别位于 `/projects`、`/memory`、`/research`、`/history`。GitHub 导入使用服务端 GITHUB_TOKEN 或系统已有 Git 凭据，不在网页输入密钥；只克隆所选分支最近 50 次提交，不安装依赖、不执行仓库代码、不拉子模块或 LFS 内容、不自动提交或推送。工作区有未提交改动、分支不符或历史分叉时拒绝自动覆盖。可复制工作区路径，在本地编辑器内修改并用 Git 提交；本版不是内置代码编辑器。

项目名称/说明与 README 外发分别授权，默认关闭；授权仅作用于绑定项目，README 每次最多按需交付 4000 字符，同步到新版本后需重新确认。项目详情可逐文件本地预览并授权有界片段，许可绑定内容与Git提交；变化或撤销后旧评估也不能沿用。项目资料不是个人记忆。真实 GitHub 导入和本地 Git 保护验收见 [项目与长期记忆续检](docs/v0-project-memory-20261026.md)。

## 快速开始

Python 3.10+，在仓库根目录执行：

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m lodestar ui --port 8124 --no-browser
~~~

打开 http://127.0.0.1:8124/ 。在本地 .env 配置服务地址、模型与密钥。示例显式暂停真实模型调用；需要离线体验时设置 LODESTAR_LLM_MODE=mock、LODESTAR_SEARCH_MODE=mock。真实调用前核实账户与所选模型的免费额度，首页加载和刷新不会调用模型。

其他系统激活虚拟环境后使用 python -m lodestar ui。旧橙色回放入口仍可使用 python -m lodestar ui --legacy；旧代码完整保留在 [codex/legacy-orange-v0](https://github.com/Marina-016/lodestar/tree/codex/legacy-orange-v0)。[旧线上演示](https://lodestar-beige.vercel.app) 是固定回放，不是新版真实后端。

本地后台、订阅检查及通知的使用方式见 [六项功能交付](docs/v0-next-features-20261026.md)。后台订阅检查默认关闭，未安装系统登录任务。最新冻结560项Python、29项前端通过；真实研究语义仍待验收。

## 简洁的 Harness

~~~text
用户消息
   ↓
当前任务的近期对话 + 有界共享记忆 + 项目范围
   ↓
模型自主决策 ←→ 搜论文 / 读论文 / 读网页 / 查任务 / 管记忆
   │                  └─ 主对话可派发子任务，各自运行
   ↓
流式回答 + 引用来源 + 运行记录
~~~

没有固定对话阶段或关键词意图分类器。只有必要的运行生命周期、操作预算、取消与数据范围检查。论文分析、项目方案和实际代码实验使用独立接口；网页聊天不会自动执行代码或采用方案。

相关实现：lodestar/agent/dialogue.py、lodestar/web/server.py、lodestar/web/tools.py、lodestar/web/memory.py。

## 数据和边界

Web 数据保存在被 Git 忽略的 workspace/web/web.db，与 CLI 研究数据库分开。旧 Web 任务会保留会话和消息，迁移为共享用户身份；旧任务备注仍是任务范围，不会自动变成个人事实。升级前应通过 SQLite backup API 备份数据库。

导入的本地仓库位于当前 Web 数据目录下的 `repositories/<工作区标识>/`。数据库自动备份含记忆和已保存的 README，不含 Git 工作区；未推送提交和未提交文件请另行备份。导入失败保留已登记项目和已创建的文件，不声称全部回滚，也不自动删除现场。

修改、停用或遗忘记忆，会重新建立受影响任务的后续上下文边界，避免旧回答重新带回失效事实。这会暂时减少模型可用的历史上下文；用户可见聊天保留。遗忘会清理该记忆的修订正文，但不会撤回云端已收到的信息，也不清理备份或聊天中原本的文字。

当前服务仅监听 127.0.0.1，针对本地单用户。**本版不是已验收的公网多用户服务。** 公网发布仍需认证、用户数据隔离、HTTPS、持久化备份、限流与真实模型/搜索验收。现有 Vercel 配置服务于旧回放，不应直接作为新版后端部署方案。

公共网页搜索可能被引擎验证拦截，错误会明确返回。阿里官方联网搜索 MCP 已有可选适配与本地免费次数预约机制；必须核实并登记剩余额度后启用，无额度不自动付费回退。模型调用开关及本地预算本身不保证云端零费用。

项目登记和绑定只建立名称、描述及范围，不代表读取或外发整仓库的授权。项目代码外发须匹配明确文件白名单。密钥、数据库、缓存和真实运行日志不进入 Git。

## V0 质量版开发

2026-10-17 起在 `codex/v0-stability-20261017` 推进质量与可靠性，相关提交已进入 master；这不等于质量门或公网发布放行。执行顺序与放行条件见 [开发计划](docs/v0-quality-plan-20261017.md)，人工语义检查见 [八组验收卡](docs/v0-quality-cases.md)，真实模型验证与剩余边界见 [10-18 验收](docs/v0-quality-review-20261018.md)。

本轮移除模型服务的隐式重试/参数降级，修复线程启动失败占住任务槽位和取消竞态；mock/DashScope 不再加载无关 Anthropic SDK。Windows 实验凭证不查询 WMI，但旧系统卡点的根因仍未查明。

固定合成证据的隔离 HTTP 验收：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_workspace --scenario quality
~~~

默认不调用真实模型，只验证管道。QF-1 是明确虚构的验收材料，快照、哈希与人工事实表分别保存；参考答案不会注入模型，不自动给研究语义打通过分。真实验收支持 Anthropic 和 DashScope 的整轮物理请求上限；这个上限不是云端免费额度总账。旧 24 次授权账本保持耗尽；追加免费验收使用独立账本、每轮请求上限及 DashScope 本地 token 预约，并保留余量。双任务在宿主续跑后可读取终稿、保存并纠正偏好；回答过长和未受证据支持的推断仍未放行。固定证据中，换用 Max 或精简提示词都未解决模型只读摘要便断言无实验的问题，因此不把模型升级或非空回答视为质量通过。学习纠正兼容合法冗余参数，记忆搜索同时披露过滤范围；有种子的召回与遗忘通过，完整连续语义仍待复核。10-18 当时的 464 项 Python 与 14 项前端通过；此前本机 HTTP 间歇性失败及复核边界见 [公开材料续检](docs/v0-public-evidence-review-20261018.md)。正文读取已补齐编号章节和 Approach/实验片段，修复通用 PDF 查询与同名缓存问题；验证范围见 [PDF 读取续检](docs/v0-pdf-evidence-review-20261018.md)。默认调用开关、模型和 .env 均未修改。

公开论文的冻结材料可通过 `--scenario public-quality --source-packet <冻结JSON路径>` 经同一隔离 HTTP 路径验收；它保留真实来源版本，正文按需交付，仍需独立人工审阅。准备方法与范围见 [公开材料续检](docs/v0-public-evidence-review-20261018.md)。报告区分实际正文与摘要回退，不以 full_text 请求参数代替阅读证据。

学习召回已修复大小写重复和超过500方法后的较早匹配遗漏，读取结果披露匹配数量与截断范围。五轮脚本覆盖过滤无匹配后概览读取、纠正与遗忘；真实语义仍待复核，详见 [记忆召回续检](docs/v0-memory-recall-review-20261018.md)。

长学习证据进入模型前限制为12000字符的序列化学习列表，放不下的正文保留为明确省略的来源引用；数据库和记忆中心保留完整原文。该限制不是整个请求或token预算，详见 [学习上下文续检](docs/v0-learning-context-review-20261018.md)。

任务结果读取现披露消息对应的运行、错误类型、消息数量与正文截断；长结果保留头尾。子任务引用元数据会与父对话实际读到的正文分开标记，详见 [任务交接续检](docs/v0-handoff-review-20261018.md)。

## 后续重点

真实模型与论文质量回归、可用的通用搜索、历史语义召回与更广环境的后台验收，以及带认证的公开服务。字面历史检索、本地后台进程和站内通知已加入当前版本。当前不自动采用技术方案，不自动判定用户掌握，不宣称固定样本实验等于论文复现。
