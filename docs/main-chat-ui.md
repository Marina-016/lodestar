# 主对话交互设计与验收

2026-11-12。延续 `ui-design.md` 的白色阅读画布、用户重点色与 Lolo，重点重做主对话可点击入口的内部界面。

## 入口及内部设计

| 入口 | 本轮处理 |
| --- | --- |
| 模型名称 | 分组展示当前空间、模型目录、自定义 ID、调用开关；保存不触发推理。目录失败保留手动输入入口。 |
| 推理按钮 | 直接聚焦当前推理选项；使用服务端能力生成可选择卡片，保存仍沿用原配置字段。 |
| 外观 | “聊天配色 / 小 lolo”两个键盘可切换的页签，配色预览、颜色选择与恢复默认保持一致。 |
| 小 lolo | 换装、自动/手动大小、动画、位置、桌面/页面状态分组；快捷菜单直接进入陪伴设置。 |
| 当前上下文 | 展示下一轮可用范围、当前模型、适用记忆、项目归属；与历史回答配置明确区分。 |
| 回答来源 | 直接打开该回答的来源页签；独立来源卡、阅读深度、原文节选、截断与技术详情。 |
| 消息操作 | 常用复制、引用和来源留在回答下方；重新生成与删除放入带解释的更多菜单。忙碌时隐藏空菜单。 |
| 删除 / 遗忘 / 撤销证据 | 应用内确认窗口展示内容预览和后果；删除失败保留目标，允许原地重试。 |
| 参考文本 | 添加、预览、展开编辑、收起、移除与选中文字引用；悬浮引用按钮限制在视口内。 |
| 任务中心 | 搜索、进行中/已完成/已归档筛选、状态卡片、从面板内新建；进入任务后可管理状态及所属项目。 |
| 记忆与学习 | 增添/编辑内容优先，保留层级、类型和日期放入更多设置；停用、恢复、遗忘与自评纠正保留原语义。 |
| 图表 | 放大、缩小、适应窗口、缩放百分比、复制代码、代码展开、SVG/PNG 导出反馈。 |
| 导航与宽度 | 保留折叠/展开、任务切换、归档显示、宽度偏好；手机导航可用 Escape 关闭并归还焦点。 |
| 发送与阅读 | 保留发送、停止、继续生成、重新生成和回到最新；不改变运行预算、来源边界或真实模型选择。 |

## 通用内部规则

- 主对话样式使用 `.chat-workspace` 限定，避免把这轮弹窗与面板布局扩散到其他页面。
- 长弹窗的标题/关闭按钮与底部主要操作保持可见。窄屏仍能查看完整表单，不产生横向溢出。
- 同一时刻只展开一个消息更多菜单；点击外部或 Escape 可关闭。
- 显示选中态、请求中状态、保存成功或失败反馈；出现失败时保留输入和目标。
- 原生 dialog 保持焦点约束；页签支持左右方向键、Home/End，并同步 ARIA 状态。

## 本地浏览器验证

使用独立 SQLite 数据库和本地 `LocalLLM`，没有读取或改写实际用户对话。任务创建/管理、项目绑定、记忆保存/停用/恢复/遗忘、学习证据纠正、模型配置保存均使用真实本地接口。

已验证：模型/推理入口定位与保存；外观两页签与键盘；配色与气泡；Lolo 服装、大小模式、动画、位置重置；上下文/回答来源分离；阅读节选及技术详情；任务搜索、筛选、归档列表、新建、完成及恢复；记忆与证据确认窗口；参考文本完整操作；消息更多菜单；发送、停止、继续和重新生成；失败删除重试；模型设置失败重试；390px 手机设置与导航；长弹窗关闭控件可见。

桌面宠物 show/stop 使用模拟 HTTP 回执验证按钮状态，没有启动或停止真实桌面宠物。图表导出验证本地 SVG/PNG 生成并拦截文件保存，避免产生下载文件。复制操作检查当前浏览器返回的成功或拒绝反馈。真实模型研究质量、外部论文内容与云端模型额度不属于本轮 UI 验收。

本轮回归结果：63 项前端、84 项相关后端测试通过；三个修改模块的 JavaScript 语法、CSS 编译与 git diff --check 通过。另以延迟请求验证：异步补全来源证据后，已展开片段和阅读位置保持不变。
