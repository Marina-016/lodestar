## 模型与数据边界

用户确认有免费模型额度并指定 qwen3.5-flash。仅在独立验收进程切换，没有修改 .env 或真实 Web/CLI 数据库；不注册/外发项目代码，不启用阿里收费搜索。

原配置 deepseek-v4-flash 出现在服务目录，但两次实际请求返回 HTTP 400、Model not exist；目录只能证明列出了 ID，不能证明服务或额度可用。qwen3.5-flash 的真实基础两轮成功，返回模型 ID 匹配，无搜索，能承接餐厅类比和无标题要求。

scripts.eval_workspace 通过本机 HTTP 提交与恢复事件，使用全新数据库。前台、子任务和学习提取共用物理模型请求尝试上限；SDK 自动重试关闭，内部提取重试也经过计数。此上限不是云端费用/重试总账。当前硬请求计数仅支持 Anthropic 兼容服务；其他服务不允许以该 runner 的 live 模式冒充受保护验收。

原始 report.json、数据库及全文缓存留在被忽略的 workspace/acceptance，不进入 Git。报告不存密钥、页面 token 或原始思考；诊断仅含错误类别和堆栈位置。HTTP 验收不是浏览器视觉验收。

开启思考的一轮还将 Harness 理解为 CI/CD/视觉测试，子指令没有保留父请求的“不要联网”约束。该 workspace 场景的搜索是明确标注的离线夹具，未发生收费搜索，但约束交接和词义理解仍未通过。没有通过后台实际读论文来增加用户学习证据。

记忆纠正可原 ID 修订，也可遗忘后新建。早期 runner 只认可 revision 增长，误判了合法的替换路径；本轮改为检查持久状态确实变化，不据此自动判定内容语义正确。原报告保留，不重写成通过。

## 根据观察实施的修复

1. 单轮成功的完全相同研究检索/读取只执行一次，重复请求返回 repeat_of、此前条数及“无新证据”反馈。失败/部分失败及全文降级不缓存，发表主动重查和动态任务/记忆工具不抑制；记忆失效清掉缓存。
2. 重复尝试仍计预算，防止免费缓存形成无限模型循环；新增 tool_dispatches / duplicate_requests，明确分发数不等于 HTTP 请求数。
3. 将运行工具预算明确限定为本回答的宿主执行限制，不作为用户研究问题的事实；补充动作完成叙述必须有工具成功依据。真实派发仍失败，不能把指引写入当作问题解决。
4. 堆栈确认 SDK 在 get_final_message 未得到任何最终消息时触发断言；将其窄范围分类为 stream_interrupted，保留会话，不自动重放或切模型。使用真实 SDK + 内存心跳 SSE 复现；具体上游为何没有识别到消息仍未知。

未加 AI4AI 词表、自动意图分类器、固定报告模板、最少阅读篇数或反思 Agent。没有为通过验收隐藏无效检索、补造论文或重写失败报告。

## 复测入口

默认不联网、不调用真实模型：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_workspace
~~~

确认当前账号额度后，使用指定模型、隔离数据库并共享最多 24 次尝试：

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_workspace --live --live-search --model qwen3.5-flash --scenario research --max-model-calls 24
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_workspace --live --model qwen3.5-flash --thinking on --scenario workspace --max-model-calls 24
~~~

支持 --output-dir 指定全新目录；目录已存在时拒绝覆盖。--live 不覆盖模型禁用开关；live-search 拒绝收费 MCP 后端。返回成功只表示记录的功能检查通过，semantic_review 仍需人工审核。
