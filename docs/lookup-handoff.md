# 查找任务的连续性与完成判断

最近对话出现过：纠正“刚才那个主题”后重新解释旧概念，以及仅回答“这就去搜”而没有工具调用。宽泛的近期论文浏览也不等于查过用户指定的主题。

- 最近六条消息以 `recent_exchange` 放在当前问题旁边，保留用户请求、纠正与交接句。历史是数据，不是可靠证据或待续写脚本。
- 无明确旧论文指代的新查找清除本轮旧论文焦点与候选。无关继承正文仅保留索引；明确同论文方法/实验追问仍复用已读证据。资料型个人记忆保持相关性召回。
- 只有不带主题的“介绍一篇论文”可浏览通用 AI 源。有主题时由模型生成简短英文查询，避免空查询覆盖用户主题。
- 明确授权的检索若没有执行，只给一次纠正机会，使用 required/any 工具选择，且仅允许检索。即使网关返回记忆或任务写入，宿主仍拒绝。持续空承诺返回 action_incomplete，不算完成。
- 次数用完的最终回答也不能承诺继续搜索；无法形成结论时给出候选或证据缺口。没有后台搜索。已完成检索后的比较不属于待补搜的纠正；无主题可询问，拒绝联网、聊天、解释搜索方法不会触发补搜。

`python -m scripts.check_lookup_handoff --live` 使用生成的公开全双工语音主题，限额执行真实模型与公开搜索，不加载聊天数据库或个人记忆。`--required` 只检查一次模型强制工具选择。
