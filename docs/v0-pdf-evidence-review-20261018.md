本轮修复正文读取与缓存的可复现缺陷，真实模型新增调用 0 次。没有更换默认模型或 SYSTEM，没有重置模型账本。论文自主取证、完整 Q07、Q05 汇总和 Q06 项目记忆场景仍待真实验收。

## 复现与修复

- 编号标题此前要么无法匹配，要么保留数字成为 `3._method` 等键，后续无法按章节取出。现统一识别 `3 Method`、`3. Method`、`3.Method`、`3) Method` 和 `3.1 Method` 等形式，保留同名章节的已有内容。
- `Approach` 被解析但没进入返回正文列表；`Experimental Results/Evaluation` 也会遗漏。现按识别出的正文节选返回，并分开披露实际返回章节和可识别章节。
- 长引言此前可能耗尽预算，使方法与实验不进入响应；每节内部裁剪也可能不标 truncated。现跨章节分配字符预算，摘要前缀有界，裁剪明确标记，返回文本不超过调用者的字符预算。未识别方法标题时仍明确回退为正文前部片段。
- 通用 PDF 曾忽略 query，并按文件名复用缓存；两个不同网址的 paper.pdf 可能返回同一缓存。现把 query 传入正文片段选择，缓存键使用完整 URL 的 SHA-256；不复用旧文件名缓存、不删除旧缓存。不同 URL 首次读取会重新下载。
- 查询片段的预算计算包含分隔符，偏移范围和匹配标记只描述实际返回的文本。查询读取不再重复附加可能挤掉正文的长摘要；题名等元数据仍由工具外层提供。
