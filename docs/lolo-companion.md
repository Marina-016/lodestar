# 小 lolo 悬浮陪伴

聊天页边角的四姿态 Q 版角色，保留原头像与主 logo。宽屏利用正文右侧留白；留白不足时收小，760px 以下隐藏。点击显示菜单，不自动发送消息或调用模型。支持指针拖动、方向键微调、Home 回到角落、Escape 收起菜单；隐藏后从右上角「外观」重新开启。位置与开关只保存在当前浏览器，配色重置不影响它们。

姿态跟随现有真实运行状态：待机、组织回答、读资料/写回答、完成后短暂招手。停止或错误回到待机。页面不可见时暂停动画，系统减少动态效果设置关闭动画。弹窗、来源抽屉打开时隐藏角色。

「外观」还支持自动适应留白、64–240 px 手动大小和动画开关；显式大尺寸可能覆盖正文，但会限制在输入框上方。窗口过矮时尺寸会临时收小，保留用户选定值。旧版本浏览器设置自动兼容，重置位置不改大小和动画。

资产 `lodestar/web/static/lolo-companion.png` 为内置 image_gen 生成的透明四宫格，依次为待机、思考、读写、招手。未使用第三方人物图片作为产品资产。

## 睡衣换装与桌面版

「外观 → 今天穿什么」可选择女仆装或紫色睡衣。睡衣素材为 `lodestar/web/static/lolo-pajamas.png`，保留原头像与主 logo。

Windows 上点击「放到桌面」会打开独立透明窗口，同时收起页面小人；「收回页面」退出桌面小人并恢复页面显示。关闭网页不会结束桌面进程。也可以从项目目录运行：

```powershell
python -m lodestar companion --skin pajamas --size 200
python -m lodestar companion --stop
```

桌面可拖动，右键可换装、调整 64–320 逻辑像素大小、40–100% 不透明度、动画、置顶和任务栏入口。双击小人打开聊天。隐藏后可双击托盘图标找回。位置、服装和尺寸保存在 `workspace/desktop-companion/settings.json`；重复启动唤醒同一窗口。

实现使用 Windows 自带 .NET Framework 编译器和 WPF，无第三方桌面包。源码随 Python 包分发，首次打开时在工作目录生成带源码哈希的可执行文件。桌面只轮询本机的 `/api/companion/status`，接收姿态和粗略运行状态，不接收聊天正文，也不会调用模型。启动/退出接口沿用本地 CSRF 校验，拒绝任意程序、路径和命令参数。

睡衣版采用内置 image_gen 编辑工具。最终提示词：保留棕色卷发、紫眼睛、星星发夹、原脸型和四宫格姿态；统一换成浅紫星星长袖长裤睡衣、奶白滚边、毛绒拖鞋，搭配带星月刺绣、白色帽边和蓬松绒球的垂尖睡帽；透明 RGBA 背景，完整身体、同一缩放、无文字和网格。

最终编辑提示词：保留 lolo 棕色卷发、紫眼睛、金色星星发夹，以及大头短身 Q 版比例；四个姿态统一换成浅紫色泡泡袖女仆裙、白色荷叶边围裙、紫色蝴蝶结、白袜和深色小鞋。保持四宫格、完整身体、相同缩放与透明背景，无文字、网格或场景。
