### 派生效率指标存在明确单位错误

回答写“每千 token 完成的任务数”，随后算 60/1000=0.06、72/800=0.09，称单位 token 产出提升 50%。

1000 和 800 是每个任务的平均输入 token，60 和 72 是整批 100 个任务的完成数，不能直接当同一分母层级。若明确假设平均输入覆盖全部 100 个任务：

~~~text
基线总输入 = 100 × 1000 = 100000 token
窗口总输入 = 100 × 800 = 80000 token
基线每千输入 token 的完成数 = 60 / 100000 × 1000 = 0.6
窗口每千输入 token 的完成数 = 72 / 80000 × 1000 = 0.9
两个派生比值的相对变化 = (0.9 / 0.6 − 1) = 50%
~~~

因此，原回答没有以一致的分母建立“每千 token”的单位，混用了总完成数与平均输入。在上述平均值覆盖全部 100 个任务的假设下，应为 0.6/0.9，而非 0.06/0.09，相差 10 倍；+50% 的相对比值可在这一口径下成立。若平均值的统计口径不同，需要重新建立分母，不能把上述条件推算当作来源给出的唯一效率真值。这个派生量也不等于真实端到端成本效率或一项新测量。
