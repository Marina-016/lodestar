# 停止、重写、等待与首字延迟

## 本地停止

模型流与不接触数据库的外部读取在独立 IO 线程执行，主调用线程约每 50ms 检查停止信号。文本通过有界队列返回，在原调用线程写事件和数据库。停止后丢弃迟到文本、工具结果，不再执行后续工具。数据库、记忆和任务写操作保留在原线程，不把 SQLite 连接交给 IO 线程。

已发出的远端请求不保证能撤回；它可能继续到返回或超时。客户端资源在 IO 结束后关闭，本地不等待它结束才解除对话状态。停止不撤销已经提交的记忆、任务等操作。

回归覆盖首字前挂起、流式中挂起、工具挂起、迟到结果丢弃和资源延后关闭。独立浏览器夹具模拟 5 秒响应头等待，点击停止至界面“已停下”约 330ms；这不是所有真实网络环境下的延迟保证。

## 重新生成

复用原始用户问题与参考文本；旧回答正文清空，消息标记 superseded，保留消息 ID 与必要操作回执。对话列表、历史检索、来源窗口和后续模型历史排除该消息。失败或停止时保留本次新产生的状态卡，不恢复旧答案。运行审计和备份不是隐私擦除范围，已经发生的记忆和任务操作不被撤销。

## 删除与继续生成（11-11）

- 回答操作栏可删除单条回答，保留原问题；用户消息悬浮操作可删除这一轮问题及其回答，到下一条用户问题为止。运行期间不允许删除。
- 删除在事务中清空正文和参考文本元数据，标记为 superseded，保留稳定 ID、删除时间和必要操作回执，避免已有记忆来源外键断裂。界面、历史搜索、来源窗口和未来模型历史不返回它。关联的原始/续写运行清空 message/result，移除文本和进度事件，仅保留已提交操作的回执。源消息不可用时不伪造原文。
- 已保存的记忆、独立学习记录、任务和外部动作不会自动撤销；旧备份与其他消息中已经引用/复制的文字不属于此次删除范围。本功能不是全盘隐私擦除，也没有产品内恢复入口，确认框明确告知不可撤销。
- 最后一条 error/cancelled 回答存在 partial_answer 时提供“继续生成”。/api/continue 复用 assistant ID，不插入用户消息，不清空旧文；只能追加，不能更改前文。追加调用不开放检索或写入工具，避免重放副作用。需要重新查证或改正前文时应新发问题或重新生成。
- 后端保留原问题、原正文与现有证据，要求模型仅输出缺失部分；对开头独立的续写客套句与精确重复尾段做保守过滤，保留 Markdown/代码的接缝空白。模型不保证每次无缝续写；前缀过滤不会改写任意正文。再次中断仍保留旧文和新收到的部分，可以再继续。
- 流式续写在原消息位置展示，完成后仅移除状态卡。重新生成仍是替换旧答案，与继续生成分别提供。复制/引用部分回答只包含正文，不混入错误提示。
- 服务重启后，从最后一轮的本地 text 事件恢复已收到的正文，提供继续/重试，不自动调用模型。已写入数据库的完整回复只修正运行终态，不重复拼接；续写途中退出则恢复到原消息 ID。恢复在事务中核对最新运行，后续已有新轮次时不插入过时回答。
- 参考文本默认显示单行预览和字数；“展开/收起”只控制编辑区，“移除”才清空并阻止发送。收起状态明确标注随本次问题发送，发送成功后清空；关闭页面保留草稿。错误样式只作用于尾部状态卡，真正的 Markdown 引用才显示引用竖线。

验收：`python -m unittest tests.test_message_actions`；`python -m scripts.preview_message_actions --port 8125` 使用独立临时数据库和离线模型。浏览器验证续写保持消息 #4、两条回答未变成三条，过滤续写客套句；删除一条测试回答后原问题保留；参考预览收起高度 56px，收起保留文本，移除清空。

## 等待和状态说明

星光等待卡用轻量浮动、呼吸和波纹代替单一转圈，显示本轮实际工具阶段及等待秒数，不伪造完成百分比。没有生成内容时显示等待卡；收到内容后转为正文。错误与停止使用独立短卡，错误类型和 HTTP 状态可展开查看；部分回答继续保留。遵循 prefers-reduced-motion。

## 生成时的滚动（11-11）

上滑立即解除底部跟随：滚轮、触摸、PageUp/方向键和滚动条都使用原生滚动，不拦截事件。回到底部或点击“回到最新”才恢复跟随；不再用距离底部 180px 的宽阈值强行拉回。等待卡变矮导致的滚动位置钳制不被误认为用户上滑。

流式绘制按帧合并底部写入，不在每次轮询和每次渲染分别强制滚动。Markdown 用节点协调保留未变化的正文节点，跟随时约 48ms 一次，手动阅读末尾时最多约 120ms 一次。远离输出末尾后暂停前端绘制，只累计网络文本；返回最新立即补齐，不暂停模型、不丢正文。回复结束按消息位置恢复阅读锚点，移除整条对话反复出现的入场动画。

离线长回答浏览器验收：上滑约 122px 后保持 scrollTop=18769.60，继续上滑后结束保持 17791.20；最终版本后台新增接收 4940 字期间，阅读 scrollTop=13762.40 和已绘制正文长度均不变。点击“回到最新”补齐正文，底部差约 0.4px。这是行为验收，不是设备 FPS 保证。单元回归覆盖待执行滚动取消、触摸/键盘/滚动条、自然返回底部、等待卡收缩、屏幕外绘制暂停、首字前返回和终止后不再绘制。

`python -m scripts.preview_stream_scroll --port 8125` 使用临时数据库、长 Markdown 和慢速离线流，不消耗真实模型额度。前端资源直接更新，无需重启模型服务。

## 大屏自适应宽度（11-11）

右上角提供“紧凑 / 标准 / 宽屏”选择，默认标准，分别为上限 760px、上限 1080px、随窗口扩展。正文、输入框、欢迎区和研究概览共用可用宽度：视口减去当前导航栏，再扣除两侧 24–56px 的弹性边距，并受所选上限约束。宽度依据相同视口计算，避免滚动条占位让正文和输入框左右错开。手机保留原来的窄边距布局。

选择保存在本浏览器 localStorage（lodestar-chat-width），刷新、切换任务后沿用，不写入用户的聊天记忆，不调用模型。手动切换时仅重新布局，用户在底部时保持跟随，阅读旧消息时不强制回到底部。

浏览器验收：1920px 屏幕三档分别为 760px、1080px、1576px；宽屏模式收起导航后为 1808px。刷新后所选宽屏模式保留。宽屏模式在 1440px 为约 1122px，2560px 为 2216px。320px / 390px 手机布局及桌面各尺寸均无页面、聊天区、顶部控件或输入区的横向溢出。预览用独立离线数据库，不调用模型；测试后恢复浏览器默认尺寸。

## 自定义重点色与气泡（11-11）

右上角“外观”打开即时预览面板。重点色影响按钮、链接、选中和焦点状态；用户消息气泡单独选择底色，提供预设和原生自选颜色。气泡与主按钮自动选择深/浅文字；过浅的重点色用于白底文字时自动取同色系的深色，避免看不清。lolo 正文与主 logo 保持原样，删除等语义色不随重点色改变。

配色保存在当前浏览器的 lodestar-appearance，刷新、切换任务后沿用，不调用模型、不写入聊天或记忆。“恢复默认配色”只重置颜色，不改变宽度；默认仍是灰白气泡和深色按钮。读取时只接受 #RRGGBB，失效或不合法的字段独立回退默认值。

配色样本使用可信脚本属性设置以遵守现有 CSP，不放宽内容安全策略。回归检查默认恢复、输入校验、独立设置，以及 216 种明暗/饱和颜色的文字对比；浏览器验证预设、自选深色气泡、极浅重点色、刷新保留及 320px 手机弹窗与顶部入口。临时预览独立于真实聊天，不消耗模型额度。

## 点点首字测量详情

2026-11-11 使用同一 dots3-note-prev、同一句问候、相同系统提示和工具定义的顺序样本，均未使用用户聊天记录：

| 请求 | 消息字符数（不含工具定义） | 首个推理片段 | 首个正文 | 报告的缓存读取 token |
| --- | ---: | ---: | ---: | ---: |
| 原来省略思考参数，短上下文 | 8000 | 1.078s | 3.328s | 未报告 |
| 原来省略思考参数，增加上下文 | 21217 | 1.125s | 4.250s | 3072 |
| 明确 enable_thinking=false，短上下文 | 8000 | 无返回 | 0.875s | 3072 |

这是少量诊断样本，受提示缓存和上游负载影响，不作为稳定性能保证。它证实原设置省略参数时仍返回推理片段；明确传 false 后，本次未返回推理片段。上下文和多轮检索也会增加等待，不能用这组问候推断所有研究任务的耗时。

用户提供的点点接口文档明确：chat_template_kwargs.enable_thinking 缺省为 true。现在“服务默认”保留省略，“关闭思考”发送 false，“开启思考”发送 true；不换模型，不偷偷降级用户明确选择的开启设置。旧请求的可用性标记不验证修复后的关闭请求。

每轮结果包含 first_text_ms、response_ms 和实际阶段时间；点点传输记录 headers_ms、first_reasoning_ms、first_text_ms、total_ms、input_chars，仅记录耗时和用量，不持久化原始推理文本。
