## 上线前未通过项

1. **真实模型全链路**：当前免费额度未重新核实。本次没有真实模型论文讲解、多轮语义理解与任务调度的验收，不能用 scripted 模型替代。
2. **通用网页搜索**：公共引擎被验证/网络问题阻断。官方阿里 MCP 已适配，但需当前核实并登记免费次数后启用；不自动使用收费额度。
3. **公网服务**：当前只绑定 127.0.0.1，无账号认证和多租户隔离。公网前需 HTTPS、认证/会话、用户归属、限流、持久化和备份恢复测试。
4. **研究质量**：相邻主题混入、摘要外推、数字/因果及发表状态误读仍需代表性真实模型回归。来源记录存在不能证明语义正确。
5. **长期任务**：线程依赖当前进程，重启会标中断；未安装永久后台和通知，长期历史语义召回未交付。

因此可以开展本地或受控单用户试用；此报告不宣称公网发布完成。旧 Vercel 服务是橙色回放，不能直接部署为新版真实后端。

## 升级与回滚

- 升级前通过 SQLite backup API 备份 workspace/web/web.db。本次备份保存在本机被忽略的 workspace/v0-check/pre-memory-migration.db。
- 先在备份副本启动新版，核对消息/任务数量和 PRAGMA integrity_check，再升级实际服务。
- 迁移不合并 CLI 数据，不删除历史聊天；旧任务备注不自动全局共享。
- 代码旧版保留在 codex/legacy-orange-v0；master 正常快进到 V0，不强推重写历史。
- 回滚需停止所有写入、保存当前数据库，再在独立目录使用旧代码及升级前数据库备份。不要用旧代码直接写新版数据库；回滚到旧备份会丢失升级后的新增数据，需要先导出保留。

密钥、数据库、缓存和验收原始运行产物不上传 GitHub。费用开关和历史免费额度不构成当前云端零费用保证。
